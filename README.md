# Aircraft Performance Calculator

A Python-based **Aircraft Performance Calculator** developed to perform fundamental aircraft performance calculations using standard aerospace engineering equations. This project provides a simple command-line interface for calculating important flight performance parameters such as lift, drag, stall speed, lift-to-drag ratio, dynamic pressure, Mach number, rate of climb, wing loading, power loading, range, and endurance.

The project is intended for aerospace engineering students, aviation enthusiasts, and anyone interested in learning the fundamentals of aircraft performance analysis through Python programming.

---

- Lift Force Calculation
- Drag Force Calculation

- Wing Loading Calculation

## Performance Parameters Included

| Parameter | Equation Used |
|-----------|---------------|
| Lift | **L = ½ρV²SCL** |
| Drag | **D = ½ρV²SCD** |
| Stall Speed | **Vs = √(2W / ρSCLmax)** |
| Lift-to-Drag Ratio | **L/D = CL / CD** |
| Dynamic Pressure | **q = ½ρV²** |
| Mach Number | **M = V / a** |
| Rate of Climb | **ROC = (Power Available − Power Required) / Weight** |
| Wing Loading | **W/S** |
| Power Loading | **W/P** |
| Range | **Breguet Range Equation** |
| Endurance | **Breguet Endurance Equation** |

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Aircraft-Performance-Calculator.git
```

Navigate to the project directory:

```bash
cd Aircraft-Performance-Calculator
```

Run the program:

```bash
python aircraft_performance.py
```
